# AWS Terraform module

This directory implements the AWS provider used by `spa provision`, `spa suspend`, `spa resume`, and `spa destroy`.

Operators configure `terraform.aws` in the environment's `splunk_config.yml` and follow [docs/aws.md](../../docs/aws.md). Do not edit generated variables, state, or inventory by hand.

## Maintainer map

- `main.tf`: EC2 instances, volumes, security-group lookup, and tags
- `variables.tf`: module inputs and validation
- `outputs.tf`: host data used to generate SPA inventory
- `terraform.tfvars`: generated by `spa provision`; never edit
- `.terraform.lock.hcl`: provider dependency lock

Terraform state belongs to `SPA_ENV_DIR`; module code belongs to `SPA_HOME`. Changes here must preserve that separation and the inventory output consumed by SPA.

Use SPA's wrapped stages and repository tests when developing this module. Raw Terraform commands are implementation diagnostics, not the documented operator interface.
